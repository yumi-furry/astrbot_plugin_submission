# 毛茸茸的跨年夜 · 活动投稿审核插件（astrbot_plugin_submission）

为 AstrBot 机器人平台开发的**纯逻辑**活动投稿插件，面向「毛茸茸的跨年夜」主题活动。完整实现多轮对话式投稿流程，支持本地文件存储 / 自建云盘上传、Excel 元数据管理、单用户每日限流，且**全程不调用任何 LLM**，所有流程由代码控制。

---

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| 🎯 **纯逻辑状态机** | 投稿流程基于会话控制器多轮对话，不依赖大模型 |
| 📚 **三类投稿** | 支持「文本 / 视频 / 音频」三大类别，每类对应独立的文件扩展名白名单 |
| 💾 **本地存储（默认）** | 投稿文件直接保存至本地目录，总容量默认 30GB 上限 |
| 📊 **Excel 管理** | 投稿元数据写入 Excel（投稿ID 自增、状态默认「待审核」） |
| ⏱️ **每日限流** | 单用户每日投稿次数默认 3 次上限，基于 Excel 记录统计 |
| 🔐 **安全过滤** | 作品名使用正则白名单过滤，文件名非法字符自动替换 |
| ↩️ **每步回退/退出** | 所有步骤支持 `上一步` 回退、`退出` 直接结束流程 |
| 🔗 **宽松联系方式** | 合作者联系方式不限制格式（QQ / 微信 / 手机号 / 邮箱任意） |
| ⏰ **会话超时** | 每步默认 60s 超时，超时自动退出流程 |

## 📁 目录结构

```
astrbot_plugin_submission/          # 插件根目录（放入 AstrBot 的 plugins 目录即可加载）
├── main.py                         # 插件主逻辑（状态机 / 文件处理 / Excel / 限流）
├── _conf_schema.json               # 插件配置 Schema（AstrBot WebUI 可视化编辑）
├── metadata.yaml                   # 插件元数据
└── requirements.txt                # 插件依赖（openpyxl、requests）
```

插件运行后会在插件目录下自动生成 `data/` 目录，结构如下：

```
astrbot_plugin_submission/data/
├── submissions.xlsx                # 投稿元数据 Excel（表头固定顺序）
└── files/                          # 投稿文件本地保存目录（默认）
```

## 🚀 快速开始

### 1. 插件安装

1. 将整个 `astrbot_plugin_submission/` 文件夹复制到 AstrBot 的 `plugins/` 目录下。
2. 重启 AstrBot，或在 AstrBot WebUI 中点击「重新加载插件」。
3. 在 AstrBot WebUI → 插件列表中找到「毛茸茸的跨年夜投稿插件」，根据需要调整配置（见下节）。

### 2. 依赖安装

若 AstrBot 未自动安装依赖，可手动进入插件目录安装：

```bash
cd astrbot_plugin_submission
pip install -r requirements.txt
```

## ⚙️ 插件配置（`_conf_schema.json`）

所有配置项均可在 AstrBot WebUI 的插件设置页面**可视化编辑**，无需手动改 JSON。

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `files_dir` | `string` | `data/files` | 投稿文件本地保存目录。可填写绝对路径或插件目录下的相对路径 |
| `max_total_storage_gb` | `float` | `30.0` | **所有用户投稿文件占用总容量上限（GB）**，超出后新投稿会被拒绝 |
| `max_single_file_mb` | `int` | `20` | **单个投稿文件大小上限（MB）** |
| `daily_submit_limit` | `int` | `3` | **单用户每日投稿次数上限**，按自然日统计 |
| `session_timeout_sec` | `int` | `60` | 投稿流程每步操作的**最大间隔（秒）**，超时自动退出 |

## 📝 使用说明

### 用户投稿流程

用户在机器人聊天中发送 `/submit` 即可开始投稿。流程为多轮对话，**每一步都可以输入：**

- **`上一步`**（或 `返回` / `后退` / `撤销` / `back` / `prev`）→ 回退到上一个步骤，并精准清空被跳过步骤的数据
- **`退出`**（或 `取消` / `结束` / `exit` / `q` / `quit` / `stop`）→ 立即结束投稿流程

**完整步骤：**

| 步骤 | 说明 | 备注 |
|------|------|------|
| 1. 询问是否投稿 | 发送 `/submit` 后机器人回复「请问你要投稿吗？（是 / 否）」 | 输入 `否` 或 `退出` 均会结束 |
| 2. 选择投稿类别 | 回复「文本 / 视频 / 音频」三选一 | 错误会提示重选 |
| 3. 上传作品文件 | 直接在对话中发送文件/图片/附件 | 会校验大小（≤配置上限）与扩展名（类别白名单） |
| 4. 填写作品名称 | 回复作品标题 | 支持中英文、数字、空格、常见标点；非法字符会提示重输 |
| 5. 是否有合作者 | 回复「是 / 否」 | 否则跳过联系方式直接保存 |
| 6. 合作者联系方式 | 回复任意联系方式（QQ / 微信 / 手机号 / 邮箱均可） | **不限制格式**，只要非空即可 |
| 7. 完成保存 | 机器人自动保存文件并写入 Excel，返回「投稿成功 + 投稿ID」 | ✅ |

### Excel 元数据表头（固定顺序）

| 列 | 说明 |
|----|------|
| 投稿ID | 自增整数（1、2、3…） |
| 用户ID | 机器人平台返回的发送者唯一 ID |
| 用户昵称 | 发送者显示昵称 |
| 类别 | 文本 / 视频 / 音频 |
| 文件名 | 上传的原始文件名（非法字符已替换） |
| 作品名称 | 用户填写的作品名 |
| 联系方式 | 合作者联系方式，无则为空 |
| 投稿时间 | `YYYY-MM-DD HH:MM:SS` |
| 状态 | 默认：**待审核** |
| 文件大小(KB) | 实际文件大小，单位 KB |

### 审核流程

当前版本仅负责**收集投稿**，管理员可通过以下方式审核：
1. 直接打开 `data/submissions.xlsx`，修改「状态」列为「通过」或「不通过」。
2. 投稿文件在 `data/files/` 目录下按「投稿ID_文件名」格式命名保存，可直接打开查看。

## ☁️ 【可选】自建云盘服务端

⚠️ **默认插件使用本地文件存储（推荐），无需部署云盘**。若需集中管理文件，可启用本项目附带的 Flask 云盘服务端。

### 云盘服务端特性
- 纯 Python / Flask 实现，跨平台
- 启动自动生成**随机 32 位 Token**，写入 `cloud_disk_server/token.txt`
- 接口：上传 `/upload`、列表 `/list`、下载 `/download/<filename>`
- 内置 Windows socket.getfqdn() 中文计算机名兼容补丁

### 启动云盘服务端

```bash
cd cloud_disk_server
pip install -r requirements.txt

# 启动（默认 0.0.0.0:5000）
python server.py

# 自定义端口/监听地址
python server.py --host 127.0.0.1 --port 8080
```

启动成功后：
- Token 会同时打印在控制台并写入 `token.txt`（请妥善保管）
- 上传的文件保存在 `cloud_disk_server/storage/` 目录
- 上传请求需在 Header 中携带 `Authorization: Bearer <你的Token>`

> 注：若要切换插件使用云盘存储，需修改 `main.py` 中保存文件的逻辑（当前默认本地），并增加对应配置项。

## ❓ 常见问题

### Q1：提示「总容量超出上限」怎么办？
A：`max_total_storage_gb` 默认 30GB。可在 AstrBot WebUI 调大该值，或清理 `data/files/` 下的旧投稿文件。

### Q2：用户今天还没投稿，为什么提示「今日投稿次数已达上限」？
A：限流基于「自然日（本地时区 00:00 ~ 23:59:59）」统计，读取 `data/submissions.xlsx` 中当日相同用户 ID 的行数。请确认 Excel 中是否存在测试数据或 ID 冲突。

### Q3：某类文件明明是 mp4，为什么提示格式不匹配？
A：检查该投稿所选类别是否为「视频」，扩展名白名单与类别是强绑定的（文本→文档类、视频→视频类、音频→音频类）。也可检查文件名是否含中文等特殊字符（插件会自动替换非法字符，但扩展名需匹配）。

### Q4：投稿流程中途被打断 / 超时后数据会保留吗？
A：不会。投稿只有完成最后一步并收到「投稿成功」提示后，才会写入 Excel 与磁盘。中途任何退出 / 超时都不会产生脏数据。

### Q5：想从「联系方式」回到「作品名称」修改，怎么做？
A：输入两次「上一步」即可：第一次从「联系方式」→「是否有合作者」，第二次 →「作品名称」。每步回退会自动清空被跳过步骤的输入（但更早步骤的数据会保留，比如类别、已上传的文件）。
